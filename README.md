# SpendWise — Personal Expense Tracker

A simple expense tracker built with HTML, CSS and vanilla JavaScript. Add your income and expenses, set a monthly budget, and see where your money goes. Your data is saved in your browser, so no backend or sign-up is needed.

## Features

- Add income and expense transactions (amount, date, description, category)
- Edit or delete any transaction
- Summary cards for total income, total expenses and remaining balance
- Search by description and filter by type, category or month
- Monthly summary for the selected period
- Monthly budget with a progress bar and an over-budget warning
- Expense breakdown by category
- Light and dark mode
- Responsive layout (works on mobile)
- Clear all data with one click

## Categories

Food, Travel, Shopping, Education, Entertainment, Bills, Other

## Project Structure

```
├── index.html   # Page structure
├── style.css    # All styling (themes, layout, responsive)
└── script.js    # App logic
```

## How to Run

1. Download or clone this project.
2. Keep `index.html`, `style.css` and `script.js` in the same folder.
3. Open `index.html` in any web browser.

## How to Use

1. Choose **Income** or **Expense**.
2. Fill in the amount, date and description (and category for expenses).
3. Click **Add Transaction**.
4. Set a monthly budget in the **Monthly Budget** section.
5. Use the search bar and filters to find past transactions.
